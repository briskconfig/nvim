# Neovim Configuration  
_[Neovim](https://github.com/neovim/neovim) is_ __not__ _my creation but I 
distribute it with this configuration for ease-of-install_  

---  

__Dependencies__:  
  - `curl` __OR__ `wget`  
  - `git`  

### Installation:

1. Copy and paste this into terminal (adds ~/.local/bin to your path)  
`curl -#L https://github.com/briskconfig/nvim/raw/refs/heads/release/bin/Install | bash ; . ~/.bashrc`  
__OR__  
`wget -S https://github.com/briskconfig/nvim/raw/refs/heads/release/bin/Install | bash ; . ~/.bashrc`
